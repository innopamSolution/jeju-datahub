## 기능 변경 상세 (hwp/pptx 설계서·요구사항 문서 갱신 시 반영 필요)

### 대시보드
- KPI 카드: 불법주정차 단속 건수 → **공영주차장 현황(1,573개소)** 로 교체 (단속 데이터 월 1회 갱신 사유)
- 민원 발생 추이: 어제/주간/월간 **모두 시간대별(00~22시) 집계** 로 통일
- 헤더 "최종 업데이트" → "최근 갱신 + ⓘ" — 호버 시 **데이터별 기준일·갱신 주기 팝오버** (민원 3종·단속·공영주차장)
- 집중구역 순위 카드: 최근 1개월 기준 명시, 'GIS 보기' → **'자세히 보기'**, 순위 배지 무채색
- 보고서 카드 항목 클릭 → 보고서 목록의 **해당 행으로 이동·강조**
- 정책 시뮬레이션·보고서 카드 **빈 상태 디자인** (안내 문구) 추가, 내보내기 버튼 제거

### 민원현황
- 지도 레이어(민원 다발/단속 집중/수요 부족 라디오) ↔ 우측 순위 카드 **연동 전환**
- 순위 목록·보고서 모두 **범례 등급(심각·경고·주의)에 해당하는 지역만** 표출
- 공영주차장 레이어: **제주시 공공데이터 CSV 1,459개소**(주차장 유형 포함) + 서귀포시 114개소
- 순위 행 클릭 → 지도 이동·팝업

### 불법 주차 집중 구역 분석
- 순위 Top7 (심각 3/경고 2/주의 2), 등급은 **절대 점수** (심각 80점↑/경고 60~79/주의 40~59)
- 종합점수 = 민원 건수 60% + 단속 40%
- 분석 기간 최소 단위 = **월** (직접설정은 월 선택 달력)
- 목록-지도 연동 (클릭 시 확대 + 팝업), 핀 라벨·숫자 축소

### 정책 효과 시뮬레이션
- **예측 기간 선택 제거**
- 주차장 확충: 확충 방식(공한지 조성/복층화/신규 조성)
- 이면도로 정비: 정비 방식(상업지역형(주차환경개선지구)/주거지역형(주민참여형)) + 정비 구간 연장(m) — 기존 '정비 유형 4종'에서 변경
- 요금제 적용: 적용 방식(요금 인상/무료→유료 전환) + 적용 급지(전체/1급지(동)/2급지(읍·면), 제주 전체·시 전체 선택 시에만) + 인상률(+10/20/30%) — 기존 '요금 급지(1~4급지)'에서 변경
- 면책 문구 상시 표출: "가정값에 기반한 시뮬레이션 결과이며 실제 정책 효과를 보장하지 않습니다."
- 효과 예측 ⓘ 분석 근거 팝오버 (혼잡 지수 정의 = (정상 이용+불법주차)÷공급 면수, 점유율 설정값 0.85)
- 시나리오 비교: **정책 유형 필터 칩(건수 병기)**, 체크박스 선택 내보내기(선택 수 표기), 행 X 삭제(확인 모달), 일시 표기
- 내보내기 보고서: 시나리오 비교 표 + **시나리오별 민원 감소율/혼잡도 개선 비교 차트 2종** (효과 요약 제거)

### 생활권 시뮬레이션
- 5단계 등급 (심각/경고/주의/보통/낮음)
  - 민원 건수·주차 수급: **백분위** (상위 10/25/50/75% 컷)
  - 혼잡도: **절대 기준** — 혼잡 지수 1.0 = 100점, 심각 ≥100/경고 90~99/주의 75~89/보통 60~74/낮음 <60
- 집중 구역 목록 Top8 (심각·경고·주의), 목록-지도 연동
- 분석 결과 요약: 격자 크기 칩 + 등급 산정 기준 ⓘ / 혼잡도 모드 혼잡 점수 안내 ⓘ

### 구역추천 (요금제·공유주차제)
- **요금제 적용(방식 전면 변경)**: 후보 = 무료 공영주차장 20면 이상. 민원 1건 → 300m 내 최근접 후보 1곳 배정(동일 읍면동). 순위 = 배정 민원 순(동률 시 면수 순). 민원 증가율은 순위 미반영 참고(직전 기간 10건 미만 '—'). 범례 = 전환 검토 우선순위(높음/중간/낮음 + 후보 아님), 산정 기준 ⓘ
- 공유주차제 적용: 종합점수(민원 40/증가율 30/단속 20/공급부족 10) 유지

### 투자·보강 우선순위 보드
- 목록 클릭 → 지도 **확대 이동 + 팝업**, 순위 표기 통일(숫자 + 등급 색 점)

### 보고서·알림
- 보고서 목록(직접 생성): 보고서명 검색·출처·생성일 필터, 행 삭제(확인 모달)
- 보고서 관리: '최근 생성 일시' = 설정이 마지막으로 보고서를 생성한 시각
- 위험단계 알림 관리 — 수신자 추가: 기본 정보 로그인 사용자 자동 입력(사용자 목록 불러오기 전환), **지역 다중 추가(+버튼·칩)**, 알림 단계 누적 선택(하위 선택 시 상위 자동), '시스템 알림' 명칭
- 알림 기준: 심각 30%/경고 20%/주의 10% + 최소 10건

### AI 어시스턴트
- 새 대화 버튼, 최근 대화 행 X 삭제(확인 모달), 설계 시나리오 2종(5월 민원 요약, 화재·과열 상관 분석) 대화 이력 포함

### 설정
- 사용자 정보 탭 제거 (메뉴 권한 관리 / 분석 지표 가중치 설정 2탭)
- 메뉴 권한: 시스템 관리자 항상 허용(해제 불가), 일반 사용자는 관리 메뉴 부여 불가, 서비스 관리자 해제 시 일반 사용자 동시 해제, **메뉴 단위 저장**
- 가중치 모델: 생활권 시뮬레이션 모델 제거 → 집중구역/구역 추천/투자·보강 3개 모델

### 공통
- 모든 삭제 동작에 확인 모달 ("삭제하시겠습니까? / 삭제하면 되돌릴 수 없습니다", 취소/삭제)
- 내보내기(PDF/DOCX)는 헤더가 아닌 각 결과 패널·필터바에 배치, 차트 이미지 포함
- 사이드바 하단: 로그인 사용자(홍길동 · 제주시 주차 정책과) + 로그아웃 확인 팝오버
